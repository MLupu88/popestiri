# PopeȘtiri — milestone roadmap

- **M0.3B — Social Intake:** linkuri publice Facebook, TikTok și YouTube trimise de operator, cu proveniență și metadata completată manual.
- **M0.3C.1 — Automated Discovery Foundation:** RSS Digi24/HotNews/G4Media, Google Trends România și YouTube Data API opțional.
- **M0.3C.1.1 — Editorial Discovery Inbox & Topic Grouping (acum):** inbox unificat, grupuri multi-sursă provizorii, ordine diversificată transparent, curățare sigură a self-group-urilor istorice și fezabilitate TikTok/Facebook.
- **M0.3C.2A — Viral Claim Radar Foundation (acum):** claim leads separate de candidate și claims verificate, extracție conservatoare, identitate YouTube publisher/channel/video, observații timestamped și UI „Afirmații în circulație”.
- **M0.3C.2A.1 — Semantic Claim Extraction Pilot:** reprocessing explicit, read-only preview/dry-run, eșantion bounded la 20, extracție multi-aserțiune cu source-grounding și cache separat; fără apeluri plătite sau promovare automată în fluxul editorial.
- **M0.3C.2B — Query generation & approved social coverage:** generare automată de query-uri din claims/topics, adaptoare aprobate TikTok/Facebook și referințe public indexate, cu provenance, limite de coverage și buget per provider. Vezi [specificația Claim Radar](claim-radar.md).
- **Următoarele etape:** dovezi și verificare, selecție în ediție, imagini cu drepturi aprobate, PDF A4 și apoi agentul de print.

Nu sunt incluse în M0.3C.2A: verdicturi AI, auto-publicare, scoruri de importanță/viralitate, scraping, integrare TikTok/Facebook activată, query generation din claims sau schimbarea timerului RSS.
